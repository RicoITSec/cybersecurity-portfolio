# Microsoft Entra ID Migration & Identity Strategy

## Objective
Design a secure hybrid-identity migration approach for an organization moving identity services toward Microsoft Entra ID.

## Scope
- Microsoft Entra Connect / Cloud Sync
- Password hash synchronization
- Single sign-on (SSO)
- Enterprise applications
- Multi-factor authentication (MFA)
- Conditional Access
- Role-based access control (RBAC)
- Least privilege
- Joiner-Mover-Leaver (JML) lifecycle controls

## Security approach
The case study focuses on reducing identity risk during migration by combining strong authentication, controlled authorization and lifecycle governance. The design uses MFA and Conditional Access to strengthen access decisions, RBAC and least privilege to limit permissions, and JML processes to reduce stale or excessive access.
