# Network Segmentation Plan

## Objective
Design a segmentation plan for a 52-device environment to reduce lateral movement and protect sensitive assets.

## Design
- Separate finance systems.
- Isolate servers.
- Segment mobile devices.
- Isolate IoT devices.
- Control inter-segment traffic with firewall policy.

## Security rationale
Segmentation limits the blast radius of a compromise and reduces unnecessary trust between device groups. Firewall-controlled flows support least-privilege network access and Zero Trust principles.
